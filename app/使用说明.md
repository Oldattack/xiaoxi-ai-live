# 小汐AI直播平台 · 使用说明

一个能自己接弹幕、自己说话、自己放歌的直播间 AI 主播。
**不用登录抖音，不用装依赖，双击就能跑。**

---

## 一、装起来（3 步）

### 第 1 步：装 Node.js（只需一次）

到 https://nodejs.org 下载 **LTS 版本**，一路下一步。

装完在命令行输入 `node -v`，能看到版本号就成。

### 第 2 步：解压

把这个压缩包解压到 **D 盘**（别放 C 盘，省空间）：

```
D:\xiaoxi-ai-live\
```

### 第 3 步：启动

双击文件夹里的 **`启动.cmd`**。

会弹一个黑窗口并打开浏览器，那就是设置页。

> 窗口别关，关了服务就停了。可以最小化。

---

## 二、第一次配置（5 分钟）

打开 `http://127.0.0.1:8792/settings`，按顺序填：

### ① 填抖音直播间号

> 设置页 → **抖音接入** → 填直播间号 → 连接

直播间号在哪找？你开播后，抖音直播伴侣/网页版地址栏里那串**纯数字**。

比如地址是 `https://live.douyin.com/123456789012`，那就是 `123456789012`。

**⚠️ 两个前提：**
- 直播间权限必须是「**所有人可进**」，只允许关注的人进是抓不到弹幕的
- 必须**正在直播中**

### ② 接语音（可选，但强烈建议）

不接的话用的是浏览器自带声音，比较机械。

> 设置页 → **说话方式** → API 密钥 → 粘贴 → 接入

支持：豆包 2.0（火山引擎）、OpenAI 兼容接口、自建接口。

没有密钥？可以先跳过，后面再接。

### ③ 调说话风格

> 设置页 → **AI 大脑**

那里可以改她的人设（她是小汐，说话短、口语化、有点憨），也可以换模型。

---

## 三、接到 OBS（关键一步）

1. 打开 OBS，在「来源」里点 **+** → 选 **浏览器**
2. 地址填：`http://127.0.0.1:8792/`
3. 宽度 **1920**、高度 **1080**
4. 勾上「**控制音频通过 OBS**」（不勾就听不到点歌和说话）
5. 确定

画面出来了，右下角是点歌台，中间是小汐。

### 直播伴侣怎么配合

**不需要配合。** 你在直播伴侣里正常开播，OBS 的虚拟摄像头接进去就行。

小汐只负责画面，不碰推流，也不会影响你的账号。

## 四、日常怎么用

| 想做的事 | 怎么做 |
|---|---|
| 开播前检查 | 设置页 → 主页 → 开始直播（自检 + 出画面） |
| 改她说话的风格 | AI 大脑 → 人设 |
| 换立绘 | 形象 → 六个表情分别替换 |
| 改点歌规则 | 点歌台 → 冷却 / 队列上限 |
| 看今天的数据 | 主页 → 今天 |

---

## 四、怎么更新

**更新只在 DSH 左侧栏的「小汐AI直播平台」里做**，设置页不用管。

```
DSH 左侧栏 → 小汐AI直播平台 → 右上角「检查更新」
有新版本 → 按钮变成「更新到 v1.7.3」→ 点一下 → 自动下载并重启
```

更新**不会覆盖 config.json**，直播间号、语音密钥、人设都保留。

> 没有装 DSH？那就重新解压新版本覆盖安装，config.json 同样不会被覆盖。

## 五、常见问题

**Q：收不到弹幕？**
A：99% 是这两个原因：① 直播间权限不是「所有人可进」 ② 还没开播。

**Q：OBS 里黑屏？**
A：浏览器源地址要填 `http://127.0.0.1:8792/`（末尾斜杠无所谓），宽高 1920×1080。

**Q：点歌没声音？**
A：OBS 里那个浏览器源的属性，勾上「控制音频通过 OBS」。

**Q：能登录抖音吗？**
A：**千万别。** 一登录，你手机上的直播伴侣会被踢下线。本平台用的是匿名旁听，不需要登录。

**Q：端口被占用？**
A：换一个：`node server.mjs --port 8793`。

**Q：她在乱说话 / 重复说话？**
A：设置页 → 弹幕与回复 → 调「同样的话不重复」的秒数；也可以加「常问常答」固定回复。

## 六、文件都在哪

```
D:\xiaoxi-ai-live\
├─ 启动.cmd          ← 双击启动
├─ server.mjs        ← 主程序
├─ settings.html     ← 设置页
├─ scene.html        ← 直播画面
├─ sprites_hd\       ← 立绘（6 个表情）
├─ config.json       ← 你的配置（改坏了删掉会恢复默认）
└─ lib\              ← 模型和语音接口
```

---

## 七、卸载

删掉 `D:\xiaoxi-ai-live` 文件夹就干净了，不写注册表、不留后台服务。

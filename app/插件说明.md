# 插件：让它出现在 DSH 左侧栏

## 一键装（推荐）

双击根目录的 **`安装到DSH.cmd`**，看到「装好了」之后：
**完全退出 DSH**（不是最小化），重新打开。

左侧栏就会多一个「小汐 AI 直播平台」，点进去直接就是设置页（内嵌面板，
带服务启停、收到/已回/延迟）。

脚本会自动做三件事：
1. 找到 `%USERPROFILE%\.dsh\profiles` 下所有 profile
2. 把 `plugin/` 复制进 profile 的 `node_modules\@local\dsh-live-agent`
3. 在 profile 的 `package.json` 里登记依赖和 bundle

> 装完**不要移动本文件夹**——插件里记的是当前安装目录的绝对路径。
> 移动了的话，重新双击一次 `安装到DSH.cmd` 即可。

## 手动装

DSH → **设置 → 插件 → 从本地安装** → 选中本包的 `plugin/` 目录 → 重启 DSH。

## 没装 DSH 也能用

双击 **`打开直播设置.cmd`**，效果一样：起服务 + 打开设置页。

## 万一 DSH 打不开了

双击 **`修复DSH.cmd`**：它会把小汐插件从 DSH 配置里摘掉，让 DSH 恢复正常启动。
（常见原因是装完插件后移动/删除了安装文件夹，DSH 找不到插件路径就不启动了。）

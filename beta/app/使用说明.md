# 小汐AI直播平台 · 使用说明

当前版本：**2.6.151**

一个 Windows 抖音直播用的 AI 虚拟主播：接弹幕、AI 回话、TTS 说话、点歌、视频点播、礼物互动，还能弹幕触发「刷抖音」。

---

## 一、装起来（3 步）

### 第 1 步：装 Node.js

到 https://nodejs.org 下载 **LTS 版本**，一路下一步。

命令行输入：

```
node -v
```

能看到版本号就成。

### 第 2 步：解压

解压到 D 盘：

```
D:\xiaoxi-ai-live\
```

### 第 3 步：启动

双击：

```
启动.vbs
```

会打开设置页：

```
http://127.0.0.1:8792/settings
```

> 窗口别关；关掉窗口等于停止服务。

---

## 二、第一次配置

### ① 抖音直播间号

```
设置 → 抖音接入 → 直播间号 → 连接
```

直播间号是开播后直播伴侣/网页地址里那串纯数字。

前提：

- 直播间权限「所有人可进」
- 正在直播中

> 不要登录抖音账号。登录会把手机和直播伴侣踢下线。

### ② 语音（可选）

```
设置 → 声音与说话 → API 密钥 → 接入
```

支持豆包、OpenAI 兼容、自建接口；没有密钥也能先用系统语音。

### ③ 人设与说话风格

```
设置 → AI 大脑
```

---

## 三、接到 OBS

1. OBS 来源点 **+** → **浏览器**
2. 地址：`http://127.0.0.1:8792/`
3. 宽 1920，高 1080
4. 勾「控制音频通过 OBS」
5. 确定

直播伴侣里正常开播，OBS 开虚拟摄像头即可。

---

## 四、弹幕刷抖音

### 打开开关

```
设置 → 内容 → 刷抖音
允许弹幕启动刷抖音 ✅
```

### 弹幕指令

| 弹幕 | 效果 |
|---|---|
| 刷抖音 / 看抖音 / 开刷抖音 | 平台自动打开 OBS，切到「小汐-刷抖音」，进入抖音推荐流 |
| 下一条 / 下一个 / 换一个 | 推荐流往下滑一条，内容一直新 |
| 停止刷抖音 / 不刷了 / 退出抖音 | 切回「小汐直播」 |

### 说明

- OBS 没打开时，平台会自动启动它（带 `--remote-debugging-port=9222`）
- 如果 OBS 已经手动打开，但没有 9222 调试端口，需要重启一次 OBS
- OBS 正在直播时，平台不会强制重启，避免中断直播
- 刷抖音时播放抖音原声（直播伴侣要开「系统声音」才收得进直播间）；说「停止刷抖音」会连同声音一起停
- 抖音网页登录建议用**另一个抖音号**，不要用直播伴侣同号
- 不会自动一直刷；只有弹幕触发才进入

### 第一次用需要扫码

```
设置页 → 内容 → 刷抖音 → 点「打开扫码窗口」
用手机抖音扫码登录（每个客户用自己的号）
```

登录态只保存在这台电脑的 OBS 里，不会跟着安装包走。

换人 / 换号时，先点「退出当前抖音」，再重新扫码。

## 五、日常使用

| 想做的事 | 怎么做 |
|---|---|
| 开播前检查 | 设置页 → 主页 → 开始直播 |
| 改人设 | AI 大脑 |
| 换立绘 | 形象 |
| 点歌 | 弹幕「点歌 歌名」 |
| 看视频 | 弹幕「看视频 名字 / BV 号」 |
| 刷抖音 | 弹幕「刷抖音」 |
| 停止刷抖音 | 弹幕「停止刷抖音」 |

> 换立绘：设置 → 形象。常态（平时样子）在「人物形象」里换；欢迎 / 生气 / 伤心 / 收到礼物 在下面单独换。
> 图片支持 PNG / JPG / WebP（≤8MB）；视频支持 MP4 / WebM（≤40MB，静音循环）。

## 六、更新

在 DSH 左侧栏「小汐AI直播平台」里检查更新。

```
检查更新 → 更新到新版本 → 自动下载并重启
```

更新不会覆盖 `config.json`。

## 七、常见问题

**Q：收不到弹幕？**
A：直播间权限不是「所有人可进」，或还没开播。

**Q：OBS 里黑屏？**
A：浏览器源地址填 `http://127.0.0.1:8792/`，宽高 1920×1080。

**Q：点歌没声音？**
A：OBS 浏览器源勾「控制音频通过 OBS」。

**Q：刷抖音没反应？**
A：

1. 设置里「允许弹幕启动刷抖音」是否打开
2. OBS 是否是平台自动打开 / 带 9222 调试端口
3. 如果 OBS 是手动打开的，重启一次 OBS
4. 抖音网页是否已扫码登录

**Q：刷抖音有声音？**
A：刷抖音期间会放抖音原声，说「停止刷抖音」就停（2.6.153 起）。不想让观众听到，关掉直播伴侣的「系统声音」。

**Q：能登录抖音吗？**
A：不要用直播伴侣同号登录。刷抖音扫码用另一个号。

**Q：端口被占用？**
A：`node server.mjs --port 8793`。

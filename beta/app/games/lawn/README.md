# 草坪守卫战 · 弹幕版

一个 1920×1080 的原创弹幕塔防网页游戏：观众发弹幕部署守卫、攒能量、挡住一波波怪物。
画面全部用 canvas 代码绘制，不含任何第三方游戏素材。

> 玩法参考了分路塔防这一通用类型；角色、名字、数值、美术均为本项目原创。

## 快速开始

```powershell
node dev-server.mjs
```

打开 `http://127.0.0.1:8899/`（假弹幕演示）。
正式直播时由小汐的 `/events` 提供弹幕，见外层 `安装说明.txt`。

## 观众指令

| 弹幕 | 效果 |
|---|---|
| `1` ~ `6` | 部署对应守卫，位置自动挑 |
| `豆炮 3-2` / `豆炮3行2列` | 精确部署到第 3 行第 2 列 |
| `3-2 豆炮` / `2号 3-4` | 反过来写也行 |
| `铲 3-2` | 铲掉那一格，退回 30% 能量 |
| `指令` | 弹出指令表 |
| 送礼物 | 加能量 |

## 守卫

| 键 | 守卫 | 能量 | 作用 |
|---|---|---|---|
| 1 | 光芽 | 50 | 每 20 秒产 25 能量 |
| 2 | 豆炮 | 100 | 单发 25 伤害 |
| 3 | 木盾 | 50 | 1600 血肉盾 |
| 4 | 冰霜炮 | 175 | 减速 55%，20 伤害 |
| 5 | 爆裂果 | 150 | 3×3 范围 2200 伤害 |
| 6 | 震地雷 | 25 | 埋 11 秒，炸一只 |

## 怪物

灰潮怪、木盔怪、旗手怪、铁壳怪、巨怪。每 5 波一次大波，30 波后进入无尽。

## 规则

- 能量全直播间共用。
- 同一个人两条指令间隔 2.2 秒；每种守卫有独立冷却。
- 怪物走到最左会触发防御锯；锯用完再漏就基地失守。
- 失守后 12 秒自动开下一局，最远波数和指挥官榜保留。
- 击杀怪物有能量赏金。

## 主播操作

| 按键 | 作用 |
|---|---|
| 空格 / P | 暂停 |
| R | 重开 |
| M | 静音 |
| 1~6 + 点格子 | 手动部署 |

## 调平衡

- `js/config.js`：初始能量、冷却、出怪节奏、产量、伤害。
- `js/data.js`：守卫价格/血量/别名、怪物血量/速度、演示昵称。

## 文件

```
games/lawn/
  index.html
  style.css
  js/config.js      布局 + 数值
  js/data.js        守卫/怪物/别名
  js/commands.mjs   弹幕解析（纯函数）
  js/game.js        循环、经济、出怪、指令
  js/draw.js        全部 canvas 绘制
  js/sfx.js         WebAudio 合成音效
  js/main.js        启动 + SSE
  dev-server.mjs    本地预览（静态 + 假弹幕）
  test-commands.mjs 指令单测
```
